# Phenumonia Dectection

This project runs on Python 3 and uses a virtual environment for package management. Follow the steps below to set it up and run.

---

## 📦 Installation

### 1. Clone the repository (if not done yet)
```bash
git clone https://github.com/yourusername/PNEUMONIA-Predection.git
cd PNEUMONIA-Predection


2. Create a virtual environment
python3 -m venv venv

3. Activate the virtual environment
  # On macOS/Linux:
    source venv/bin/activate
    #On Windows (Command Prompt):
    venv\Scripts\activate


4. Install dependencies
  #command for install depandencies
   pip install -r requirements.txt

5. Running the Project
#    To run the main Python file, use:
     python3 main.py

6. Optional: Train the model (if needed)
#    If your project includes training logic, run:
     python3 train.py


✅ Notes
Make sure you're using Python 3.6 or higher.

Don't forget to activate your virtual environment before running the code.
If you make changes to the environment, don't forget to update requirements.txt:
    //command to add the packages into requirements .txt file
     pip freeze > requirements.txt
